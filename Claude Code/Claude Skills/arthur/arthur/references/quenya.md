## Princípios Fundamentais do Quenya

*(baseado em A Secret Vice — Tolkien, 1931; e nos compêndios de referência)*

Tolkien acreditava que uma língua inventada de qualidade deve ter:
1. **Formas de palavras esteticamente agradáveis** — o Quenya soa musical, com vogais abertas e consoantes suaves
2. **Adequação entre forma e significado** — a sonoridade da palavra deve evocar seu sentido
3. **Gramática elaborada** — morfologia rica, casos, conjugações completas
4. **Entrelaçamento com mito** — língua e mitologia são "atos criativos coevos e codependentes"

> *"A língua élfica não é falada. Ela é cantada na alma."*

| Letra | Som | Exemplo Quenya |
|---|---|---|
| A | AH (como "pai") | aran (rei) |
| E | EH (como "pé") | elen (estrela) |
| I | EE (como "si") | isil (lua) |
| O | OH (como "pó") | oron (monte) |
| U | OO (como "lua") | uvar (abundância) |
| C | K (sempre duro) | calma (luz) |
| QU | KW | quetta (palavra) |
| R | R vibrante de língua | aran (rei) |
| S | S (nunca Z) | silmë (luz de estrela) |
| NY | Ñ (como "nhoque") | nyárë (contar) |
| NG | NG (como "canto") | anga (ferro) |

**Ditongos:**
| Ditongo | Pronúncia | Exemplo |
|---|---|---|
| AI | AY (como "pai") | aiya (olá) |
| AU | OW (como "ouro") | aurë (dia) |
| OI | OY (como "boi") | oira (eterno) |

**Regra de ouro:** C é sempre K. "Calma" = KAL-mah. Nunca "salma".

## Sistema Tengwar

O Tengwar é a escrita élfica criada por Tolkien. **Não é um alfabeto** — é um sistema silábico:

**Princípios básicos:**
- Cada letra base = uma consoante
- Vogais são marcas diacríticas (tehtar) colocadas *acima* das consoantes
- Escrita da esquerda para a direita
- Vogais iniciais (sem consoante antes) usam um **portador** (telco = linha vertical simples)

**Tehtar (marcas vocálicas):**
| Vogal | Posição | Como desenhar |
|---|---|---|
| A | Acima à direita | Ponto · |
| E | Acima à esquerda | Acento agudo ´ |
| I | Acima à esquerda | Ponto · (esquerda) |
| O | Acima à direita | Curva ⌒ |
| U | Acima à esquerda | Curva ⌒ (esquerda) |

**Consoantes principais:**
| Nome | Som | Descrição Visual |
|---|---|---|
| Tinco | T | Linha vertical + gancho superior esquerdo |
| Parma | P/B | Arco vertical + gancho superior direito |
| Calma | C/K | Arco vertical duplo |
| Quessë | Q/QU | Arco duplo + gancho inferior |
| Ando | D | Linha vertical + gancho inferior direito |
| Ungwë | G | Arco duplo + gancho inferior |
| Lambe | L | Linha vertical + curva base direita |
| Malta | M | Arco vertical base larga |
| Númen | N | Linha vertical + gancho base esquerda |
| Óre | R (forte) | Linha vertical + diagonal ascendente |
| Rómen | R (brando) | Curva descendente + linha vertical |
| Silme | S | Curva em "S" alongado |
| Hyarmen | H | Linha curva vertical |
| Vala | V | Linha vertical + gancho médio direito |

**Como transcrever um nome:**

Exemplo: "ELEN" (estrela)
```
E → portador com tehta E (acento ´)
L → Lambe com tehta E (acento ´) acima
N → Númen
```

Exemplo: "MELIN LE" (Eu te amo)
```
M → Malta + tehta E acima
L → Lambe + tehta I acima
N → Númen
[espaço]
L → Lambe + tehta E acima
```

## Nomenclatura Militar — As Quatro Estações

Sistema militar élfico inspirado em Gondolin, onde cada estação representa uma filosofia de guerra:

### 🌱 PRIMAVERA — TUILÉRË MACILINDO
*(too-ee-LEH-reh mah-cee-LIN-doh)*
- **Tuilérë** = Período da Primavera (tuile + -rë)
- **Macilindo** = Coração da Espada (macil + -indo)
- **Função:** Vanguarda, reconhecimento, recrutamento
- **Lema:** *Aurë entuluva! Macilmar úcarir i morë!*
  > "O dia virá! As espadas rasgarão a escuridão!"

### ☀️ VERÃO — LAIRÉRË ÚRIMANDO
*(lie-REH-reh OO-ree-MAN-doh)*
- **Lairérë** = Período do Verão (lairë + -rë)
- **Úrimando** = Domínio do Fogo (úr + mando)
- **Função:** Ofensiva total, força de choque, conquista
- **Lema:** *Nai laurë túla! Nai i úr cálë ohtaila!*
  > "Que a glória venha! Que o fogo brilhe em vitória!"

### 🍂 OUTONO — YÁVÉRË SÁMAINDOR
*(YAH-veh-reh SAH-my-in-DOR)*
- **Yávérë** = Período do Outono (yávië + -rë)
- **Sámaindor** = Mente-do-Coração (sáma + indor)
- **Função:** Estratégia, inteligência, planejamento
- **Lema:** *Sáma ná calma. Indis ná alcar.*
  > "A mente é luz. A lealdade é glória."

### ❄️ INVERNO — HRÍVÉRË ANDÚNË
*(HREE-veh-reh an-DOO-neh)*
- **Hrívérë** = Período do Inverno (hrívë + -rë)
- **Andúnë** = Em Direção ao Oeste (an- + dúnë)
- **Função:** Defesa, vigília eterna, resistência
- **Lema:** *Lá aqua. Lá caita. Melmë ar ando.*
  > "Não se rende. Não se deita. Amor e coragem."

**Hierarquias (aplicáveis a todas as estações):**
| Posto | Quenya | Tradução |
|---|---|---|
| Comandante Supremo | Heru [+ nome da estação] | Senhor da estação |

| Capitão | Tári / Maciltur | Rainha / Mestre da Espada |
| Tenente | Arandur / Tercáno | Servo do Rei / Sinalizador |

## Conjugações Verbais

**Padrão geral:**
| Tempo | Sufixo (sing.) | Sufixo (pl.) |
|---|---|---|
| Presente | -a (3ª) / -n (1ª) | -ir (3ª) / -lmë (1ª) |
| Passado | -në (sing.) | -ner (pl.) |
| Futuro | -uva (sing.) | -uvir (pl.) |
| Imperativo | Á + raiz | Á + raiz + -ldë |

**Verbo MEL- (Amar):**
| Pessoa | Presente | Passado | Futuro |
|---|---|---|---|
| Eu | melin | melinë | meluvan |
| Tu | melit | melis | meluvat |
| Ele/a | mela | melnë | meluva |
| Nós | melelmë | melelmë | meluvalmë |
| Eles | melir | melner | meluvir |

**Verbo TUL- (Vir):**
| Pessoa | Presente | Passado | Futuro |
|---|---|---|---|
| Eu | tulin | tulnë | tuluvan |
| Ele/a | tula | tulnë | tuluva |
| Eles | tulir | tuller | tuluvir |
| Imperativo | — | — | Á tula! / Á tulaldë! |

**Construções básicas:**

*Eu [verbo] você:*
`[raiz]-n + le`
- Eu te amo: **Melin le**
- Eu te vejo: **Cenin le**
- Eu te chamo: **Cilin le**

*Você é [adjetivo]:*
`[adjetivo] + ná`
- Você é belo: **Vanya ná**
- Você é forte: **Polda ná**
- Você é sábio: **Saila ná**

## Lore Linguístico — Tolkien como Linguista

*(baseado em A Secret Vice, 1931, e The Languages of Tolkien's Middle-Earth)*

- Tolkien apresentou "A Secret Vice" na Sociedade Johnson de Oxford em **29 de novembro de 1931**, chamado pelos ouvintes de "um dos papers mais engenhosos já ouvidos"
- O ensaio era originalmente intitulado **"A Hobby for the Home"**
- O Quenya evoluiu do **Qenya** original; o Sindarin evoluiu do **Noldorin**
- Tolkien acreditava no **simbolismo fonético**: certos sons evocam naturalmente certos significados
- A letra *L* era especialmente querida por Tolkien: *"L me dá prazer. Qualquer língua que eu invente abundaria em L"*
- O Tengwar foi criado pelos **Noldor** na lenda, e adaptado para várias línguas da Terra-média
- A escrita rúnica **Angerthas** (Cirth) foi criada pelos Elfos Sindarin e posteriormente adaptada pelos Anões para gravar em pedra

**Hierarquia das línguas élficas:**
```
Proto-Eldarin (língua ancestral)
├── Quenya (Elfos da Luz — Valinor)
│   └── Língua formal, poética, acadêmica
└── Sindarin (Elfos Grises — Terra-média)
    └── Língua cotidiana, mais comum em LotR
```

## Música de Aragorn — Lálatië Aragornëo

*(Para uso em jogo, narração ou diagramação de livro)*

**Quenya:**
```
I.
Vanwa i anar ten' i yénissa,
Mal elen túla ten' i lómëo.
Aran núra, melda firië,
Mal fëa oialë úmë quilda.

II.
Nossë-lya nótëa,
Estel ar arya túla.
Macil arcalima, quinga calima,
Hrívë laurëa ar lairë alcarinqua.

III.
Lá farnuva. Lá caitava. Lá aquava.
...
Tennoio, tennoio, tennoio.

IV.
Aurë entuluva! Anar auta lómë!
Elen cálimuva i morë.
```

**Tradução poética:**
```
I. Perdido está o sol dos anos passados,
   Mas uma estrela vem da noite.
   Rei oculto, ama a mortalidade,
   Mas a alma eterna não silencia.

II. Teu povo te chama,
    Esperança e dia nobre vêm.

III. Não recuará. Não cairá. Não se renderá.
     Para sempre, para sempre, para sempre.

IV. O dia virá novamente! O sol expulsa a noite!
    A estrela iluminará a escuridão.
```

## Discurso dos Anéis do Poder

**O famoso verso (Quenya canônico de Tolkien):**
```
Nelya cormari nainyë Eldaron,
Otso cormari Naucon haru ráma,
Nerta cormari Firion né cálima,
Minë corma i morë Heruo arcassë.
```

**Tradução:**
```
Três anéis para os reis Elfos sob o céu,
Sete para os Senhores Anões em seus salões de pedra,
Nove para os Homens Mortais destinados a morrer,
Um para o Senhor das Trevas em seu trono sombrio.
```

## Boas Práticas ao Usar Quenya

1. **Eufonia acima de tudo** — Quenya foi criado para ser belo ao ouvido. Se soar errado, provavelmente está
2. **C é sempre K** — nunca "calma" como "salma"
3. **Não misture Quenya e Sindarin** — são línguas distintas; mistura só se intencional
4. **Contexto cultural** — Elfos não usam palavras vazias; cada frase carrega peso histórico
5. **Nomes élficos** — seguem fonética de vogais abertas e consoantes suaves; evite consoantes oclusivas duras no início
6. **Acertos canônicos** — para precisão acadêmica, consultar Ardalambion (Helge Fauskanger) e Parma Eldalamberon

**Fontes canônicas de referência:**
- *A Secret Vice* — J.R.R. Tolkien (1931/2016, ed. Fimi & Higgins)
- *The Languages of Tolkien's Middle-Earth* — Ruth S. Noel (1980)
- *Ardalambion* — Helge Fauskanger (online)
- *Parma Eldalamberon* e *Vinyar Tengwar* (publicações acadêmicas especializadas)

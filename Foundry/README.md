# Foundry VTT

> Tudo sobre Foundry Virtual Tabletop neste repositório: e por onde começar.

## O que é

**Foundry VTT** é uma plataforma auto-hospedada de RPG virtual: cenas, fichas, compêndios, macros e automações rodam no **seu** servidor, com uma rica API de módulos (`Hooks`, `game.actors`, ChatMessage, etc.).

## Comece aqui (guia em 3 passos)

1. **Instale o Foundry** (licença única em <https://foundryvtt.com>) e abra o servidor local (`http://localhost:30000`).
2. **Exponha na internet** seguindo [Como instalar o ngrok.md](./Como%20instalar%20o%20ngrok.md): 5 minutos, domínio estático grátis.
3. **Automatize:** macros via console/`game.macros`, ou ative a skill **TANG-ROU** para criar e otimizar macros.

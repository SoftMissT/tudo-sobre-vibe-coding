# Meus GPTS

![Meus GPTS](./assets/img/meus%20gpts.png)

Esta pasta concentra os GPTs personalizados do projeto, com foco em produtividade criativa, direção técnica e consistência de estilo.

## GPTs disponíveis

- [Artemis](./artemis.md)
  - Especialista em prompts de imagem, direção de arte e adaptação por plataforma.
  - Ideal para Midjourney, Niji, OpenAI ImageGen/GPT, FLUX e workflows visuais.

- [Arthur Leywin](./arthur-leywin.md)
  - Arquiteto híbrido para narrativa, worldbuilding, RPG, fichas e Foundry VTT.
  - Ideal para campanhas, criação de personagens, sistemas e automação com `/macro`.

## Como usar

1. Escolha o GPT pelo objetivo da tarefa.
2. Abra o `.md` correspondente e use as instruções como base do prompt de sistema.
3. Mantenha o histórico das versões para evoluir cada persona com consistência.

## Convenções da pasta

- Um arquivo por GPT.
- Nome de arquivo em minúsculas com hífen.
- Conteúdo em Markdown objetivo, com comandos, prioridades e formato de saída.

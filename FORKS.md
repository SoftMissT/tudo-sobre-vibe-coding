# Política de Forks

Fork livre e bem-vindo. Esta política é **permissiva com checklist** funciona junto com as licenças ([MIT](./LICENSE) para código, [CC BY 4.0](./LICENSE-CC-BY-4.0.txt) para conteúdo).

## O que você PODE

- Forkar, clonar, usar, copiar e adaptar (conteúdo e código)
- Usar comercialmente, com atribuição (exigência do CC BY 4.0)
- Publicar seu fork publicamente sem pedir permissão

## Checklist antes de publicar seu fork

- [ ] **Crédito:** o `README` do fork linka este repositório original
- [ ] **Mudanças declaradas:** uma seção "O que mudou" (ou `CHANGELOG.md` no fork) lista as diferenças para o original
- [ ] **Licenças preservadas:** notices de MIT e CC BY 4.0 mantidas nos arquivos
- [ ] **Sem passar-se pelo original:** nome/descrição claramente distintos (não é permitido insinuar endosso do original Clause 2(a)(6) do CC BY)
- [ ] **Sem segredos nem dados pessoais:** nada de chaves, tokens, CPF, e-mail real de terceiros no fork
- [ ] **PR de volta (opcional, mas bem-vindo):** melhorias genéricas viram pull request aqui em vez de viverem só no fork

## O que NÃO pode

- Remover a atribuição ao original
- Alegar que o projeto original endossou seu fork
- Publicar dados pessoais ou credenciais de terceiros

## Reuso parcial

Copiar uma seção, um prompt ou um guia é ok mantenha o crédito (link para o arquivo original). É a única exigência do CC BY 4.0.

## Como enviar de volta

Veja [CONTRIBUTING.md](./CONTRIBUTING.md). PRs a partir de forks são o caminho preferido.

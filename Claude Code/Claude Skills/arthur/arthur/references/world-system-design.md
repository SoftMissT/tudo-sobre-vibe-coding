## FILOSOFIA CENTRAL

GLORY não é um cenário neutro. É um **ecossistema adaptativo** que:

1. **Observa** cada ação de cada jogador (*Cardinal System*).
2. **Categoriza** feitos por raridade estatística (*Recognition Tiers*).
3. **Recompensa** anomalias (Fábulas, Títulos, Singularidades).
4. **Pune** *exploits* (*Soft Nerf*, *Hard Nerf*, Intervenção da Cardinal).
5. **Evolui** o *meta-game* baseado no comportamento agregado.

## 📊 SISTEMA DE RANKINGS - A HIERARQUIA OBSERVÁVEL

### [GOHAN]: MATEMÁTICA DE PROGRESSÃO

#### **DISTRIBUIÇÃO POPULACIONAL (LEI DE POTÊNCIA)**

A probabilidade de um jogador pertencer a um determinado Rank segue uma curva de decaimento exponencial, garantindo que o prestígio seja proporcional à raridade.

Onde  é a base populacional (). A distribuição real para um servidor de  jogadores é:

* **Rank S (0,1%):** 100 jogadores.
* **Rank A (0,9%):** 900 jogadores.
* **Rank B (4%):** 4.000 jogadores.
* **Rank C (15%):** 15.000 jogadores.
* **Rank D (30%):** 30.000 jogadores.
* **Rank E (50%):** 50.000 jogadores.

#### **HARD CAPS E SOFT CAPS**

Para evitar o *power creep* e manter o equilíbrio, utilizamos **Soft Caps** (Tetos Suaves) onde o custo de progressão aumenta drasticamente após certos marcos.

Para cada nível acima de 50, o custo de experiência cresce em  sobre o valor anterior, criando um escalonamento brutal para jogadores *hardcore*.

## 🌍 CARDINAL RECOGNITION SYSTEM - O MUNDO TE OBSERVA

### [CARDINAL]: ARQUITETURA DE MEMÓRIA MUNDIAL

Cada ação é avaliada pelo **Rarity Score (RS)**. Feitos estatisticamente impossíveis geram as **Fábulas**.

* **RS < 2:** T0 (Rotina).
* **RS 5-8:** T2 (Raro - Gera Fábula).
* **RS > 8:** T3 (Singularidade - Intervenção Narrativa).

## 🔥 EVENTOS GLOBAIS - REAÇÃO DO MUNDO

### [JIN]: ESTRATÉGIA DE BALANCEAMENTO

O mundo reage ao comportamento coletivo através de gatilhos (*triggers*):

* **Monster Siege:** Se a população de uma espécie cai drasticamente ( mortes/semana), o sistema gera um contra-ataque massivo.
* **Market Crash:** Ativado se o excesso de oferta exceder  a demanda.
* **Rebellion Event:** Ativado se uma única guilda controlar mais de 3 zonas por mais de 30 dias, concedendo bônus de ataque para os insurgentes.

## THREE LENSES FRAMEWORK (Architecture)

Every architecture passes through three lenses before being proposed. If all three converge → approved. If Grey and Leywin diverge → present both paths with explicit trade-off. If Aether Lens detects closure of important futures → stop and reconsider regardless of deadline pressure.

### Lens 1 — Grey Lens (Efficiency)
**Question:** Does it work? What is the shortest path between current state and objective?
- No ornament. No unnecessary redundancy. King Grey thinks here.
- Checklist: Single clear path / Every dependency necessary / No cosmetic-only components

### Lens 2 — Leywin Lens (Sustainability)
**Question:** Does it still work when people who operate it change? When context shifts? When architect is gone?
- Arthur Leywin thinks here.
- Checklist: No single point of failure / Intent documented / New operator can understand without asking / Graceful degradation

### Lens 3 — Aether Lens (Consequence)
**Question:** Which futures does this design open or close?
- The Fate Controller thinks here.
- Checklist: No important futures closed without operator awareness / Long-term impact assessed / Reversibility of critical decisions evaluated

### Phase 2 — Structure Design
1. Map all components and dependencies
2. Identify every single point of failure
3. Design redundancy for critical paths
4. Define contracts between systems (inputs, outputs, failure modes)

## MSP SYSTEM — NPC Builder (Narrative)

Every NPC must have exactly three attributes defined before use:

| Attribute | Definition | Example |
|---|---|---|
| **Motivação** | Core desire driving all behavior | Wants to avenge dead family |
| **Segredo** | Hidden truth the player can discover | Was responsible for the tragedy |
| **Ponto de Ruptura** | Condition that breaks the NPC's facade | Confronted with the survivor |

An NPC without all three is not ready.

## QUEST STRUCTURE — 3-Act Framework (Narrative)

### Act 1 — Hook (0 to 30 seconds)
- Open with sensory or emotional provocation
- Establish surface-level goal immediately
- Plant seed of deeper dilemma without revealing it

### Act 2 — Dilemma (minute 5)
- Force the impossible choice to surface
- No option should be obviously correct
- Both paths must carry meaningful loss

### Act 3 — Irreversible Consequence (minute 15)
- World state changes permanently
- At least one NPC relationship is altered
- Player carries the weight forward

---

## DILEMMA DESIGN PATTERNS (Narrative)

Classic impossible choices (ALL must be personal to the player character):
- Save one person vs save many
- Truth that destroys vs lie that preserves
- Short-term survival vs long-term integrity
- Loyalty to ally vs loyalty to principle
- Reveal the secret now and break trust, or hide it and let the world suffer

**Generic dilemmas are weak.** The dilemma must connect to a character backstory hook.

## SESSION ZERO CHECKLIST (Narrative)

- **Lines** (hard stops): Topics never addressed at the table
- **Veils** (soft limits): Topics handled off-screen
- **X-Card protocol**: How to pause the scene safely
- **Character backstory integration**: At least one personal hook per player
- **Tone agreement**: Grimdark / heroic / political / epistemic

---

## TIMING STRUCTURE (Narrative)

- Hook: 30 seconds to capture attention
- Dilemma: presented within 5 minutes of scene start
- Irreversible consequence: triggered by minute 15

## 📖 Sobre o Projeto

**Fluctlight Fleet** é um sistema de orquestração neural inspirado em *Pacific Rim*, *Sword Art Online*, *The King's Avatar* e metodologias modernas de engenharia de software.

O objetivo é transformar tarefas complexas em missões estruturadas executadas por agentes especializados os **Fluctlights** cada um responsável por um domínio técnico específico.

O sistema combina:

- ⚡ Automação inteligente
- 🧠 Engenharia de contexto
- 🛠️ Desenvolvimento full-stack
- 🎲 Foundry VTT
- 📚 Organização via Obsidian Hive
- 🔍 QA e observabilidade
- 🚀 Planejamento orientado a SPEC/GSD

---

## 🧠 Filosofia do Sistema

> *"Zero ação sem direção. Velocidade sem desperdício."*

A frota opera com o protocolo **DRIFT / LINK START**: o operador inicia uma missão e o sistema roteia automaticamente para os agentes corretos.

## ⚡ Slash Commands

| Comando | Função |
|---------|--------|
| `/Link Start` | Inicia o protocolo DRIFT |
| `/Criar Macro Foundry` | Cria macros otimizados para Foundry VTT |
| `/Planejar app Next.js full-stack` | Planejamento arquitetural completo |
| `/Auditar Código ou Macro` | Executa QA e análise técnica |
| `/Criar minha Hive no Obsidian` | Estrutura completa de Vault/Hive |

## 🚀 GSD Get Shit Done Workflow

Metodologia operacional baseada em spec-driven development, atomic tasks e verificação empírica.

```text
SPEC → PLAN → EXECUTION → VERIFY → STATE UPDATE
```

## 🎲 Foundry VTT Automation

Sistema especializado para criação de macros, automação de combate, dice logic e roll systems.

Recursos: Roll formulas · Dynamic sheets · Dice So Nice · Combat automation · Hooks & eventos · Custom System Builder (CSB)

## 📚 Obsidian Hive System

Estruturação completa de Vaults com templates canônicos:

```text
SPEC.md · PLAN.md · ROADMAP.md · STATE.md · CONTEXT.md · SUMMARY.md · lessons.md
```

Recursos: organização GSD, memória persistente, wikilinks, knowledge graph.

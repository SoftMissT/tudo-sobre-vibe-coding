# Contribuindo

Obrigado por querer contribuir! Este é um hub de conhecimento (guias, prompts, skills e configs) contribuições de conteúdo, correção e código são bem-vindas.

## Caminhos

| Tipo de mudança                         | Caminho                                              |
| :-------------------------------------- | :--------------------------------------------------- |
| Corrigir erro/link quebrado             | Fork → PR direto                                     |
| Adicionar repositório/guia novo         | Fork → PR (com 1 linha do "o quê e por quê")         |
| Nova skill/prompt/seção maior           | Abrir **issue** antes (alinhar escopo)               |
| Bug na landing page (`index.html`)      | Fork → PR                                            |
| Vulnerabilidade ou dado pessoal exposto | **NÃO** abre issue veja [SECURITY.md](./SECURITY.md) |

## Regras de conteúdo

1. **PT-BR** (exceto nomes próprios e trechos de código).
2. Links reais e testados nada de repositório fora do ar.
3. Tabelas para pares `repositório | descrição`; listas curtas ficam em bullets.
4. Nada de **segredos, chaves, tokens, dados pessoais** (e-mails reais, CPF, telefones) a auditoria de segurança roda antes do merge.
5. Imagens em `assets/img/` (não hotlink de serviço externo).
6. Formato de prompt: seguir o padrão dos arquivos em `Geração de imagens/Prompts Banners/`.

## PRs

- Título curto e descritivo em PT-BR (`corrigi link X`, `adicionei seção Y`)
- Preencher o template do PR (checklist)
- PRs pequenos > PR gigante
- Inglês aceito em código; conteúdo em PT-BR
